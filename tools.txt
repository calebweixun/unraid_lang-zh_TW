此實用程式用于故障排除。它將收集所有系統資訊和設定檔案，並將這些檔案打包到一個可以儲存在本地的 ZIP 檔案。
隨後，此檔案可以包含在您與 Limetech 或 UnRAID 论坛的通信中。

這有助于其他人快速獲取您系統的内部資訊，並為您的問题提供更好的支援。將收集以下資訊
和設定檔案:
:end

:diagnostics_2_plug:
+ */config*
<br>復制所有的 *\*.cfg* 檔案、*go* 檔案和 *super.dat* 檔案。這些都是是設定檔案。
+ */config/shares*
<br>復制所有的 *\*.cfg* 檔案。這些是使用者共享設定檔案。
+ *Syslog file(s)*
<br>復制目前的 *syslog* 檔案和以前存在的任何 *syslog* 檔案。
+ *System*
<br>儲存以下命令的輸出：
<br>lsscsi、lspci、lsusb、free、lsof、ps、ethtool 和 ifconfig。
<br>顯示 IOMMU 組。
<br>顯示命令行参數（例如 PCIe ACS 覆盖、PCI 存根等）。
<br>儲存系統變數。
+ *SMART reports*
<br>儲存系統中存在的每個磁碟的 SMART 報告。
+ *Docker*
<br>儲存檔案 *docker.log*、*libvirtd.log*、*libvirt/qemu/\*.log* 和 *vfio-pci*。
:end

:newconfig_plug:
該實用程式用于重設陣列磁碟設定，以使所有磁碟都顯示為“新”磁碟，
就好像它是全新的伺服器一样。

当您新增或刪除了多個驱動器並且希望基于新設定重建奇偶校驗時，
此功能很有用。

重設陣列***之後***，使用 *'保留目前分配'* 选項填充所需的磁碟插槽。預設情況下，**不**填充磁碟插槽。

**請勿使用此實用程式，因為它会重建故障驱動器** —— 它將产生相反的效果，
將***無法***重建現有的故障驱動器 —— 您已受到警告！
:end

:newperms_1_plug:
從 5.0 之前的 Unraid 伺服器版本升級到 Unraid v5 或更高版本之後，必須执行這項一次性操作。
执行這項一次性操作時，選擇**所有磁碟**。

從 Active Directory 過渡到非 Active Directory 集成時，
該實用程式還可用于還原檔案和目錄的預設所有權/權限。

該實用程式將啟動一個後台進程，該進程將存取每個資料磁碟和快取磁碟，
選擇使用者共享並將檔案和目錄所有權更改為*無人/使用者*（即 uid / gid 更改為 99/100），
並按以下方式設定權限：
:end

drwxrwxrwx

对于讀/寫檔案：
-rw-rw-rw-

-r--r--r--
:end
