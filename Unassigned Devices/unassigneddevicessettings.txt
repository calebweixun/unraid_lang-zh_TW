:ud_settings_smb_security_plug:
> 設定 SMB 共享的使用者等級。
>
> + 設為**關閉**以關閉 SMB 共享。
> + 設為**公共**將以公共讀寫權限共享裝置、遠端 SMB/NFS 共享和 ISO 掛載。
> + 設為**私有**為 SMB 共享啟用 SMB 安全。按使用者設定讀寫權限。
> + 設為**私有且隱藏**為不可見的 SMB 共享啟用 SMB 安全。按使用者設定讀寫權限。
>
> Windows 伺服器簽名：
>
> 在使用 Windows 11 24H2 或更新版本時，如無法瀏覽 SMB 共享，你需要針對一項叫作“伺服器簽名”的新功能作出更改。伺服器簽名在 Unraid 中為啟用狀態，你需要更改一些設定才能訪問公共共享。
> 你可以<u><a href='https://techcommunity.microsoft.com/t5/storage-at-microsoft/accessing-a-third-party-nas-with-smb-in-windows-11-24h2-may-fail/ba-p/4154300', target='_blank'>_(disable it in Windows)_</a></u>，或者在啟用伺服器簽名的情況下使用 Unraid——最簡單的方法是在 Unraid 中建立一個與 Windows 賬戶同名的使用者並設定密碼，然後 Windows 將要求你提供憑據。
> 如果你使用的是微軟賬戶，最好先在 Unraid 中建立一個帶密碼的使用者，然後在 Windows 的“控制面板->憑證管理器->Windows 憑證->新增 Windows 憑證”處新增正確的 Unraid 伺服器名稱和憑證。
:end

:ud_settings_case_sensitive_plug:
> 決定檔名是否區別大小寫。
>
> 預設值**自動**允許 Linux CIFS 和 NFS 等區別檔名大小寫的客戶端以封包為單位報告 Samba 伺服器它們希望以區別檔名大小寫的方式訪問檔案系統（以支持 Unix 檔名區別大小寫的語義）。Windows 系統不區別檔名大小寫，因此設為自動對於 Windows 系統來說等效於設為否；不過，Windows 客戶端傳遞的檔名的大小寫會被保留。此選項可導致處理大型目錄時效能下降，因為 Samba 必須搜尋匹配傳遞的檔名。
>
> **是**意味著建立檔案時，檔名使用客戶端傳遞的大小寫，並且只有使用同樣大小寫的檔名才能訪問此檔案。相比之下，這不會影響大型目錄的訪問速度，但在此項設定下，某些 Windows 應用程式可能無法正常運轉。比如，遠端檔名為“MyFile”，Windows 應用程式在開啟“MYFILE”時就會失敗，儘管在 Windows 的原生環境中，檔名大小寫是不區別的。
>
> **強制小寫**特殊在於，來自客戶端的所有檔名，不僅僅是新檔名，都將轉為小寫。換句話說，無論在 Windows 一側有著怎樣大小寫的檔名，此檔案都將在遠端端以小寫檔名儲存和訪問。這保證了所有 Windows 應用程式都能正確尋找任何檔案，而不管檔名大小寫；但在列出資料夾時，檔名的大小寫不會保留。
:end

:ud_remote_server_test_plug:
> 需要遠端伺服器啟用 SMB 和/或 NFS。此功能將檢查 SMB 和/或 NFS 埠聯通性。此外，還要求 Unraid 的“showmount -e &lt;server&gt;”指令能夠顯示可用 NFS 掛載。

> 若要 SMB 顯示為線上狀態，遠端伺服器的 SMB 埠必須能夠聯通。

> 若要 NFS 顯示為線上狀態，遠端伺服器的 NFS 埠必須能夠聯通，並且 Unraid 側“showmount -e”指令能夠顯示 NFS 共享。
> 某些情況下，埠能夠聯通，但“showmount -e”不顯示 NFS 共享，此時 NFS 也無法使用。

> 對於實際能夠連線的遠端伺服器，比如一臺 Synology 裝置，若 showmount 指令不返回任何 NFS 共享，你可能遇到了以下幾種情況之一： 

> NFS 共享沒有匯出：

> 伺服器可能沒有設定以 NFS 匯出任何目錄。請檢查 Synology 裝置的 NFS 設定，確保 NFS 共享的目錄已匯出。

> 訪問受限：

> NFS 共享可能設定了 IP 訪問限制。Synology 裝置允許為每個 NFS 共享指定允許訪問的 IP 地址或網路。如果你的 IP 地址被限制，NFS 共享就不會在 showmount 指令輸出中列出。

> 未啟用 NFS 服務：

> Synology 裝置上的 NFS 服務可能沒有啟用。在 Synology DSM 的“控制面板->檔案服務->NFS”處檢查 NFS 服務設定，如果發現 NFS 服務關閉，請開啟它。

> 防火牆或網路設定不當：

> Synology 裝置的防火牆規則可能阻止了 showmount 指令的請求或必需的 RPC 通訊。確保防火牆設定允許 NFS 相關埠的流量。通常，NFS 服務使用埠 2049，RPC 使用埠 111。

> Synology 匯出選項設定不當:

> 對於 NFSv3 協議的客戶端，Synology NFS 設定有時會要求在頂層啟用 NFS 服務並允許 NFSv3 協議。檢查“控制面板->檔案服務->NFS”，確保設定得當。

> 確保 NFS 服務啟用，設定了正確的權限，並且允許向你的客戶端 IP 匯出目錄後，showmount 指令應該能夠列出可用的匯出。
:end
